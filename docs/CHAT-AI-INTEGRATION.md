# ادغام چت و هوش مصنوعی هم‌قدم

## تصمیم معماری
این بسته دو پروژهٔ کامل را کنار HTML کپی نمی‌کند؛ این کار به‌تنهایی آن‌ها را اجرا نمی‌کند و دو سامانهٔ حساب/داده ایجاد می‌کند. هم‌قدم از قبل به Supabase متصل است. این بسته قابلیت‌های سازگار را روی همان زیرساخت فعال/تقویت می‌کند.

## یافته‌های سورس‌ها

### Open WebUI
آرشیو دریافت‌شده یک پلتفرم AI مستقل با فرانت‌اند Svelte و بک‌اند Python است؛ از Ollama و APIهای سازگار با OpenAI پشتیبانی می‌کند و در README قابلیت‌هایی مانند نقش‌ها، چندمدلی، ابزار، RAG، جست‌وجوی وب، فایل/دانش، Markdown/LaTeX، صدا/ویدئو و مدیریت usage را معرفی می‌کند. این قابلیت‌ها در ZIP همگی به‌صورت ماژول‌های مستقل قابل کپی نیستند: بخش زیادی به بک‌اند، وابستگی‌ها، مدل و تنظیمات جداگانه وابسته است.

### Tinode Web
آرشیو دریافت‌شده نسخهٔ 0.25.4 کلاینت React وب Tinode است. README خودش صریحاً می‌گوید «فقط فرانت‌اند» است و برای پیام‌رسانی به سرور Tinode نیاز دارد. مواردی مانند مخاطب‌ها، پیام، forward، تماس/اعلان (با تنظیمات جداگانه)، و بین‌المللی‌سازی از تجربهٔ آن الهام‌بخش‌اند، اما وصل‌کردن مستقیم آن به Supabase بدون آداپتور و تغییر مدل احراز هویت/داده ممکن نیست.

## چیزی که در هم‌قدم فعال/تقویت می‌شود

1. index.html: واردکردن ماژول موجود src/ai-assistant.js؛ این ماژول قبلاً در سورس بود اما در پوستهٔ اصلی وارد نشده بود.
2. src/ai-assistant.js: پاسخ دستیار با Markdown پایهٔ امن (تیتر، پاراگراف، فهرست، نقل‌قول، لینک HTTP(S) و کد) نشان داده می‌شود. HTML خام پاسخ به‌عنوان markup اجرا نمی‌شود؛ متن کاربر همچنان text-only می‌ماند.
3. چت عمومی src/public-chat.js، پنل پشتیبانی src/support-chat.js و پیام‌رسان خصوصی/گروهی src/hamghadam-suite.js حفظ می‌شوند. سورس فعلی امکانات زنده/Realtime، اتاق‌ها، پاسخ، واکنش، ویرایش/حذف، پیوست و میزبان گروه/کانال را پیاده کرده است؛ آن‌ها دوباره با Tinode جایگزین نمی‌شوند.
4. یک آزمون ادغام اضافه می‌شود و یک assertion نادرست در آزمون آپلود اصلاح می‌شود: فراخوانی واقعی .upload() در چندخط نوشته شده و regex قدیمی آن را نمی‌دید.

## اتصال به Supabase موجود

- Project ref: gnbwcupxtbsjdgnncort (rahe-talabegi-app).
- جدول‌های public_chat_rooms, public_chat_messages, public_chat_reactions, public_chat_attachments, support_conversations, support_messages, ai_conversations و ai_messages روی پروژهٔ زنده موجودند و RLS برای جدول‌های مربوط فعال است.
- Edge Functionهای hamghadam-ai و hamghadam-admin فعالند. تابع AI نشست را بررسی می‌کند، مالکیت گفتگو را می‌سنجد و نوشتن تاریخچه را سمت سرور انجام می‌دهد.
- این پچ به‌تنهایی دیتابیس زنده را تغییر نمی‌دهد. بستهٔ ارتقای کیفیت migration افزایشی جداگانه برای تم/صوت سراسری و حذف محدودشدهٔ پیام/پیوست‌ها اضافه می‌کند؛ آن migration باید پس از پشتیبان‌گیری و بازبینی، جداگانه روی پروژهٔ هدف اجرا شود.
- وجود/اعتبار Secret به نام OPENAI_API_KEY را از ابزار متصل نمی‌توانم بخوانم یا تنظیم کنم؛ کلید باید فقط در Secrets تابع Edge باشد. اگر تنظیم نشده باشد، UI خطای روشن برمی‌گرداند. هرگز service-role یا کلید مدل را در فرانت‌اند/Android قرار نده.

## مجوزها و برندینگ

Tinode Web دارای Apache-2.0 است و در توزیع مشتق باید notices آن حفظ شوند. آرشیو Open WebUI دارای مجوز مخصوص خود پروژه است، نه MIT/Apache؛ محدودیت‌های درج‌شده در LICENSE، به‌ویژه قواعد برندینگ، باید رعایت شوند. این ادغام فایل‌های اصلی/برندینگ آن دو پروژه را در UI هم‌قدم کپی نمی‌کند و فقط تجربه‌ها/الگوهای سازگار را پیاده می‌کند.

## ساخت ZIP کامل
اسکریپت مک/ویندوز در بستهٔ ارتقای کیفیت، آخرین سورس مخزن را clone می‌کند، هر دو مرحلهٔ پچ را اعمال می‌کند، سپس تست و build را اجرا می‌کند و پس از موفقیت ZIP کامل سورس را با نام Hamghadam_Quality_Complete_Replacement.zip می‌سازد. خود KIT جایگزین کامل برنامه نیست و به‌صورت خودکار روی GitHub push نمی‌کند.
