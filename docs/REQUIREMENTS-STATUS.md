# وضعیت پوشش اَبَرپرامپت راهِ طلبگی

این فایل وضعیت **نسخهٔ کد حاضر** را صادقانه دسته‌بندی می‌کند؛ ساخته‌شدن منو یا یک رابط، به معنی تکمیل علمی همهٔ محتوای همان حوزه نیست.

| بخش اَبَرپرامپت | وضعیت در این نسخه | توضیح |
|---|---|---|
| محصول فارسی، RTL و تک‌فایلی آفلاین | پیاده‌سازی شده در نسخهٔ دسکتاپ | فایل مستقل HTML حفظ شده است؛ ذخیره‌سازی مرورگر ممکن است بسته به مرورگر/مبدأ محدودیت داشته باشد. |
| حفظ و ادغام راه‌دان | پیاده‌سازی شده | HTML کامل راه‌دان داخل برنامه تعبیه شده و آزمون تطابق منبع دارد. |
| نمای امروز و ناوبری | پیاده‌سازی شده | صفحه‌های اصلی و نقطهٔ ورود پشتیبانی موجودند. |
| برنامه‌ریز روزانه/فعالیت‌ها | پیاده‌سازی پایه | ویژگی‌های موجود را می‌توان ادامه داد؛ تقویم کامل زمان‌بندی بلوکی و همگام‌سازی ابری نیست. |
| هدف‌ها و گام‌های پیشرفت | پیاده‌سازی پایه | پیشرفت بر مبنای گام‌های ثبت‌شده در نسخهٔ موجود محاسبه می‌شود. |
| مطالعه، فلش‌کارت و آزمون عربی | پیاده‌سازی/ادغام پایه | محتوای کامل همهٔ کتاب‌ها یا بانک سؤال جامع تضمین نشده است. |
| اخلاق، عقاید، سواد رسانه‌ای، امر به معروف، خانواده، وحدت، خوراکی‌ها و منابع | ساختار آموزشی موجود، پژوهش محتوا جزئی/ناقص | همهٔ مطالب نیازمند بررسی منبع‌به‌منبع هستند؛ این نسخه ادعا نمی‌کند تمام احادیث، فتاوا، اسناد تاریخی یا شواهد پزشکی را گردآوری کرده است. |
| پشتیبان JSON و اعتبارسنجی | پیاده‌سازی و آزمون‌شده | آزمون‌های فعلی قبول/رد ساختارهای نمونه را بررسی می‌کنند؛ تست end-to-end مرورگر انجام نشده است. |
| نسخهٔ اندروید با Capacitor | سورس و پیکربندی آمادهٔ ساخت | پروژهٔ native Android/APK در این محیط ساخته نشده است؛ به Android Studio/SDK نیاز دارد. |
| ورود و چت پشتیبانی | کد کلاینت، پنل، مهاجرت SQL آماده | تا ساخت پروژهٔ Supabase، قرار دادن کلید عمومی و اجرای migration به سرویس واقعی متصل نیست. |
| دسترسی نقش پشتیبانی و RLS | سیاست‌های SQL آماده و ایستای کد آزموده‌شده | هنوز با دیتابیس زنده و حساب‌های واقعی تست نفوذ/دسترسی نشده است. |
| اعلان Push، پیوست فایل/تصویر، چندکارشناس، گزارش مدیریتی | انجام نشده | در README به‌عنوان موارد بعدی ثبت شده‌اند. |
| انتشار عمومی پنل/اپ و لینک عمیق احراز هویت | انجام نشده | دامنه، HTTPS، تنظیمات Auth/redirect و انتشار نیاز است. |

## آزمون‌های اجراشده

- `npm test`: ۱۳ آزمون موفق، ۰ ناموفق.
- `node --check src/support-chat.js`: موفق.
- `node --check src/support-utils.mjs`: موفق.
- `node --check vite.config.js`: موفق.

این‌ها آزمون‌های محلی/ایستای کد هستند. `npm run build`، اجرای کامل در مرورگر واقعی، اتصال زندهٔ Supabase و ساخت APK هنوز در این محیط تأیید نشده‌اند.

## افزودهٔ بستهٔ پیوست امن

- کد رابط پیوست در src/public-chat-attachments.js و اعتبارسنجی در src/public-chat-attachment-utils.mjs اضافه شده است.
- migration در supabase/migrations/20261027150000_public_chat_attachments.sql ایجاد جدول metadata، bucket خصوصی، سقف ۵۰ MiB و سیاست‌های عضویت اتاق را تعریف می‌کند.
- این قابلیت تا اجرای دستی migration روی پروژهٔ Supabase واقعی و آزمون با دو حساب عضو، «آمادهٔ استقرار» است و نباید «تأییدشده در محیط زنده» نامیده شود.
- فایل‌ها در bucket خصوصی ذخیره می‌شوند؛ لینک دانلود امضاشده یک‌ساعته است. نوع فایل‌های مجاز در migration فهرست شده‌اند.
